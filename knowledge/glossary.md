# 游戏策划术语表（Glossary）

> 目的：人机协作时的**共同语言**。AI 用术语提问/描述，用户用术语反馈感受，避免歧义。
> 使用：文档/对话里出现术语时以本表定义为准；新术语随时补充。

## 核心循环相关

| 术语 | 定义 |
|---|---|
| 核心循环（Core Loop） | 玩家反复执行的最小动作闭环：动作→反馈→成长→更复杂动作 |
| 分钟级循环 | 玩家一分钟内的重复动作序列 |
| 小时级循环 | 让玩家玩一小时/一天的动力（解锁、推进） |
| 生涯级循环 | 让玩家玩一周/一月/一年的动力（成就、排行、速通） |
| 压缩循环（Compulsion Loop） | 短周期高回报的循环设计（社交/放置游戏常见） |

## 手感相关

| 术语 | 定义 |
|---|---|
| 手感（Game Feel） | 输入+响应+表现 三要素构成的操控体验 |
| 土狼时间（Coyote Time） | 离开平台边缘后短暂时间内仍可起跳的容错窗口 |
| 跳跃缓冲（Jump Buffer） | 落地前短暂时间内按跳键，落地后立即起跳的容错 |
| 可变跳高（Variable Jump） | 跳跃高度随按键时长变化（按久跳高） |
| 顿帧（Hit-stop） | 命中瞬间画面短暂停顿，增强打击感 |
| 空气控制（Air Control） | 跳跃中左右转向的灵敏度 |

## 设计理论相关

| 术语 | 定义 |
|---|---|
| MDA 框架 | 机制(Mechanics)→动态(Dynamics)→美学(Aesthetics) 三层设计框架 |
| 心流（Flow） | 挑战与能力匹配时的沉浸状态 |
| 心流通道 | 难度≈能力的体验区间，两端是焦虑区和无聊区 |
| 难度曲线 | 挑战难度随游戏进度的变化线 |
| 阶梯教学 | 新机制按"演示→组合→压力测试"逐步引入 |
| 死亡即教学 | 重试成本极低，失败即学习路径的设计 |
| 涌现（Emergence） | 少量规则组合产生大量玩法的系统现象 |

## 内容与随机相关

| 术语 | 定义 |
|---|---|
| 程序生成（Procedural Generation） | 算法生成内容（关卡/地图）而非手工制作 |
| 可控随机 | 有约束规则、保证可解与公平的随机生成 |
| 危险-回报（Risk-Reward） | 高风险区域配高回报的设计 |
| 风险可读性 | 玩家能否在行动前预见危险 |

## 项目管理相关

| 术语 | 定义 |
|---|---|
| MVP | 最小可玩闭环：3~5 个功能构成"先能玩"的版本 |
| M0~M3 | 里程碑：原型→核心闭环→内容扩充→打磨上线 |
| 验收标准 | 每个功能的"做成什么样算完成" |
| ADR | 设计决策记录（背景/选项/决策/后果） |
| P0/P1/P2 | 功能优先级：必须/重要/锦上添花 |
| 占位美术（Placeholder） | 开发期用的临时图形/音频，正式资产后替换 |
