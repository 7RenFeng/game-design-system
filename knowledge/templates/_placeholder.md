# 题材变体模板（预留）

> 说明：不同题材的策划案骨架差异较大（RPG 要数值经济/装备系统，肉鸽要随机性设计，模拟经营要经济循环）。
> 当前 TEMPLATE.md 是通用骨架，可覆盖所有题材；本目录按需添加题材专属章节补充。

## 待添加的题材变体（按需创建，命名 `<题材>.md`）

- [ ] RPG / 俯视角：数值成长、装备/技能系统、任务结构、经济平衡（参考 `theory/balance.md`）
- [ ] 肉鸽：随机性设计、死亡循环、build 系统（参考 `theory/randomness.md`、`cases/spelunky.md`、`cases/downwell.md`）
- [ ] 模拟经营 / 放置：经济循环、产出-消耗闭环（参考 `theory/balance.md`）
- [ ] 解谜：谜题结构、难度阶梯、提示系统
- [ ] 塔防：波次设计、单位平衡、地图布局
- [ ] 平台跳跃：手感参数表、关卡模块化（参考 `theory/game-feel.md`、`cases/celeste.md`）

## 添加模板的规则

1. 复制 TEMPLATE.md 对应章节结构，只增不改通用部分
2. 每个变体说明：该题材的**核心风险** + **策划案必填的专属章节** + **参考知识卡片**
3. 更新 `knowledge/INDEX.md` 索引表
